# Arkan Vault

## Identidade

O Arkan Vault é uma camada de memória persistente e local para agentes de IA. Seu objetivo é armazenar, relacionar e recuperar conversas, decisões, tarefas, ideias, documentos e outros conhecimentos em uma estrutura única e extensível.

Esta é a memória canônica do próprio projeto: ela permite que o Arkan Vault conheça sua finalidade, sua arquitetura e a direção planejada.

## Modelo central

Tudo é um `MemoryObject`. Não existem modelos separados para ideia, tarefa ou pessoa; o campo `type` distingue cada categoria. Uma memória possui ID global no formato `mem_{uuid4_hex}`, título, resumo, conteúdo Markdown, projeto, tags normalizadas, relações, contexto, caminho do arquivo e timestamps UTC.

O campo `context` registra como e onde a memória foi criada, sem exigir alterações no banco: origem, agente, dispositivo, local, idioma e sessão.

## Arquitetura

- `api/`: interface HTTP e validação de entrada.
- `services/`: regras de negócio e orquestração.
- `storage/`: persistência substituível.
- `core/`: primitivas sem estado, como tags, Markdown, embeddings e ranking.
- `events/`: barramento desacoplado de eventos.
- `plugins/`: integrações futuras que consomem eventos.

No MVP, os metadados ficam no SQLite, o conteúdo em arquivos Markdown e os vetores semânticos no ChromaDB. Os embeddings são produzidos localmente com sentence-transformers.

## Capacidades atuais

- Criar, listar, consultar, atualizar e excluir memórias.
- Filtrar por tipo, projeto e tags.
- Fazer busca textual, semântica e híbrida.
- Persistir conteúdo em Markdown, metadados no SQLite e embeddings no ChromaDB.
- Exibir uma visualização gráfica das memórias e de suas relações.
- Publicar eventos relevantes do ciclo de vida das memórias.

## Estado do projeto

A arquitetura do MVP está congelada. A API funcional e a persistência básica foram concluídas, assim como a busca e a primeira versão do grafo visual. A evolução deve preservar as regras de dependência já definidas.

## Destino planejado

O Arkan Vault será executado continuamente em um notebook Dell antigo usando Linux, funcionando como servidor pessoal na rede local. Outros computadores, celulares e agentes poderão consultar a memória pela LAN e, futuramente, por acesso remoto seguro.

A expansão futura inclui uma biblioteca de arquivos para imagens, vídeos, documentos, programas e arquivos grandes. Esses arquivos deverão ser servidos eficientemente pela rede local, enquanto o acesso externo deverá usar um túnel seguro como Tailscale ou WireGuard. Hermes será um projeto integrado futuramente, mas permanece fora do escopo atual.

## Princípio

O Arkan Vault deve continuar local-first, portátil, legível por humanos e independente de um único provedor. A memória deve poder ser migrada para outra máquina copiando seus dados persistentes e recriando apenas o ambiente de execução.
