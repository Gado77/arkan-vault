# Projetos Principais

## Arkan Vault

Meu principal projeto atualmente.

O Arkan Vault é uma camada de memória persistente para agentes de IA. Seu objetivo é armazenar conhecimento, recuperar apenas o contexto relevante e fornecer esse contexto para agentes como Hermes e outras ferramentas.

Não é um aplicativo de notas. É uma base de conhecimento inteligente construída para IA.

Os princípios do projeto são:

* arquitetura modular;
* memória persistente;
* busca semântica;
* Markdown como formato principal;
* banco relacional para metadados;
* banco vetorial para contexto;
* API própria;
* foco em MVP e evolução incremental.

---

## Loopin TV

Sou fundador do projeto Loopin TV.

A Loopin TV é uma plataforma de mídia indoor baseada em telas distribuídas em estabelecimentos comerciais da minha cidade.

O modelo de negócio consiste em vender espaços publicitários para empresas locais, exibindo anúncios em academias, supermercados e outros pontos estratégicos.

O projeto envolve:

* gestão de clientes;
* planos comerciais;
* reprodução automática de mídia;
* gerenciamento remoto das telas;
* player próprio;
* infraestrutura em TV Box;
* integração com APIs;
* automação de conteúdo.

Tenho interesse em evoluir a Loopin TV para uma plataforma profissional de Digital Signage.
